# Component index

Every reusable component in one table: its class, the header that declares
it, its group's guide, and what it is for. Search this page for the thing you
need ("table", "toast", "keyboard"), then open the header: each one starts
with a usage example. The guides list every style knob, slot, event and cue.

All components live in `src/ui/components/`, in namespace `hui::ui`, and
follow the same five rules ([COMPONENTS.md](COMPONENTS.md)): a public `style`
(a `ui::Theme` plus the component's own knobs), `set_bounds(rect)`,
`handle(input, feedback)` returning a `ui::Event`, `update(dt)` and a const
`draw(canvas)`. `#include "ui/components.hpp"` brings in all of them.

This table is generated by `tools/gen-docs.py` from the guides in
`docs/components/`; do not edit it by hand.
