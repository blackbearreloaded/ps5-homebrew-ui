# ps5-homebrew-ui

A reference for building polished, console-grade user interfaces for PS5
homebrew with OpenGL: a small rendering and motion kit, a sound system with
ready-to-use effects, and one native app that holds many complete UI designs.
Press **L1** / **R1** to switch between them.

Work in progress: the full guide and the design gallery land with the designs.

```bash
make                  # build the PS5 app folder in dist/
make host-snapshots   # run every design on the PC and write PNGs to build/snapshots
make test             # unit and tooling tests
```
